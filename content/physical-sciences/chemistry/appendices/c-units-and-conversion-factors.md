**Units of Length**

| Unit | Equivalents |
|---|---|
| meter (m) | = 39.37 inches (in.) |
| meter (m) | = 1.094 yards (yd) |
| centimeter (cm) | = 0.01 m (exact, definition) |
| millimeter (mm) | = 0.001 m (exact, definition) |
| kilometer (km) | = 1000 m (exact, definition) |
| angstrom (Å) | = $10^{-8}$ cm (exact, definition) |
| angstrom (Å) | = $10^{-10}$ m (exact, definition) |
| yard (yd) | = 0.9144 m |
| inch (in.) | = 2.54 cm (exact, definition) |
| mile (US) | = 1.60934 km |

**Units of Volume**

| Unit | Equivalents |
|---|---|
| liter (L) | = 0.001 m³ (exact, definition) |
| liter (L) | = 1000 cm³ (exact, definition) |
| liter (L) | = 1.057 (US) quarts |
| milliliter (mL) | = 0.001 L (exact, definition) |
| milliliter (mL) | = 1 cm³ (exact, definition) |
| microliter (µL) | = $10^{-6}$ L (exact, definition) |
| microliter (µL) | = $10^{-3}$ cm³ (exact, definition) |

| liquid quart (US) | = 0.25 (US) gallon (exact, definition) |
| liquid quart (US) | = 0.9463 L |

**Units of Mass**

| Unit | Equivalents |
|---|---|
| gram (g) | = 0.001 kg (exact, definition) |
| milligram (mg) | = 0.001 g (exact, definition) |
| kilogram (kg) | = 1000 g (exact, definition) |
| kilogram (kg) | = 2.205 lb\* |
| ton (metric) | = 1000 kg (exact, definition) |
| ton (metric) | = 2204.62 lb |
| ounce (oz) | = 28.35 g |
| pound (lb) | = 0.4535924 kg |
| ton (short) | = 2000 lb (exact, definition) |
| ton (short) | = 907.185 kg |
| ton (long) | = 2240 lb (exact, definition) |
| ton (long) | = 1.016 metric ton |

\* Strictly speaking, the ounce and pound are units of weight, $W$ (a force equal to the product of mass and gravitational acceleration, $W = mg$). The conversion relations in this table are commonly used to equate masses and weight assuming a nominal value for $g$ at the surface of the earth.

**Units of Energy**

| Unit | Equivalents |
|---|---|
| 4.184 joule (J) | = 1 thermochemical calorie (cal) |
| 1 thermochemical calorie (cal) | = $4.184 \times 10^{7 }$ erg |
| erg | = $10^{-7}$ J (exact, definition) |
| electron-volt (eV) | = $1.60218 \times 10^{-19}$ J = 23.061 $\text{kcal}\ \text{mol}^{-1}$ |
| liter∙atmosphere | = 24.217 cal = 101.325 J (exact, definition) |
| nutritional calorie (Cal) | = 1000 cal (exact, definition) = 4184 J |
| British thermal unit (BTU) | = 1054.804 J\* |

\* BTU is the amount of energy needed to heat one pound of water by one degree Fahrenheit. Therefore, the exact relationship of BTU to joules and other energy units depends on the temperature at which BTU is measured. 59 °F (15 °C) is the most widely used reference temperature for BTU definition in the United States. At this temperature, the conversion factor is the one provided in this table.

**Units of Pressure**

| Unit | Equivalents |
|---|---|
| torr | = 1 mm Hg (exact, definition) |
| pascal (Pa) | = $\text{N}\ \text{m}^{-2}$ (exact, definition) |
| pascal (Pa) | = $\text{kg}\ \text{m}^{-1}\ \text{s}^{-2}$ (exact, definition) |
| atmosphere (atm) | = 760 mm Hg (exact, definition) |
| atmosphere (atm) | = 760 torr (exact, definition) |
| atmosphere (atm) | = 101,325 $\text{N}\ \text{m}^{-2}$ (exact, definition) |
| atmosphere (atm) | = 101,325 Pa (exact, definition) |
| bar | = $10^{5}$ Pa (exact, definition) |
| bar | = $10^{5}\ \text{kg}\ \text{m}^{-1}\ \text{s}^{-2}$ (exact, definition) |
