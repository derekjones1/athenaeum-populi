**Fundamental Physical Constants**

| Name and Symbol | Value |
|---|---|
| atomic mass unit (amu) | $1.6605402 \times 10^{-27}$ kg |
| Avogadro’s number | $6.02214076 \times 10^{23}\ \text{mol}^{-1}$ |
| Boltzmann’s constant ($k$) | $1.380649 \times 10^{-23}\ \text{J}\ \text{K}^{-1}$ |
| charge-to-mass ratio for electron ($e/m_\text{e}$) | $1.75881962 \times 10^{11}\ \text{C}\ \text{kg}^{-1}$ |
| fundamental unit of charge ($e$) | $1.602176634 \times 10^{-19}$ C |
| electron rest mass ($m_\text{e}$) | $9.1093897 \times 10^{-31}$ kg |
| Faraday’s constant ($F$) | $9.6485309 \times 10^{4}\ \text{C}\ \text{mol}^{-1}$ |
| gas constant ($R$) | $8.205784 \times 10^{-2}\ \text{L}\ \text{atm}\ \text{mol}^{-1}\ \text{K}^{-1}$ = $8.314510\ \text{J}\ \text{mol}^{-1}\ \text{K}^{-1}$ |
| molar volume of an ideal gas, 1 atm, 0 °C | $22.41409\ \text{L}\ \text{mol}^{-1}$ |
| molar volume of an ideal gas, 1 bar, 0 °C | $22.71108\ \text{L}\ \text{mol}^{-1}$ |
| neutron rest mass ($m_\text{n}$) | $1.6749274 \times 10^{-27}$ kg |
| Planck’s constant ($h$) | $6.62607015 \times 10^{-34}$ J s |
| proton rest mass ($m_\text{p}$) | $1.6726231 \times 10^{-27}$ kg |
| Rydberg constant ($R$) | $1.0973731534 \times 10^{7}\ \text{m}^{-1}$ = $2.1798736 \times 10^{-18}$ J |
| speed of light (in vacuum) ($c$) | $2.99792458 \times 10^{8}\ \text{m}\ \text{s}^{-1}$ |

*Source note:* four of these values — Avogadro’s number, Boltzmann’s constant, the fundamental unit of charge, and Planck’s constant — are the exact values that have defined the SI units since 2019. The other values are older measured ones, so the exact values do not reproduce them to the last digit: Avogadro’s number times the fundamental unit of charge is $9.648533212 \times 10^{4}\ \text{C}\ \text{mol}^{-1}$, and Avogadro’s number times Boltzmann’s constant is $8.314462618\ \text{J}\ \text{mol}^{-1}\ \text{K}^{-1}$.
