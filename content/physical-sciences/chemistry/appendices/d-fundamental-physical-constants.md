**Fundamental Physical Constants**

| Name and Symbol | Value |
|---|---|
| atomic mass unit (amu) | $1.6605391 \times 10^{-27}$ kg |
| Avogadro’s number | $6.02214076 \times 10^{23}\ \text{mol}^{-1}$ |
| Boltzmann’s constant ($k$) | $1.380649 \times 10^{-23}\ \text{J}\ \text{K}^{-1}$ |
| charge-to-mass ratio for electron ($e/m_\text{e}$) | $1.75882001 \times 10^{11}\ \text{C}\ \text{kg}^{-1}$ |
| fundamental unit of charge ($e$) | $1.602176634 \times 10^{-19}$ C |
| electron rest mass ($m_\text{e}$) | $9.1093837 \times 10^{-31}$ kg |
| Faraday’s constant ($F$) | $9.6485332 \times 10^{4}\ \text{C}\ \text{mol}^{-1}$ |
| gas constant ($R$) | $8.205737 \times 10^{-2}\ \text{L}\ \text{atm}\ \text{mol}^{-1}\ \text{K}^{-1}$ = $8.314463\ \text{J}\ \text{mol}^{-1}\ \text{K}^{-1}$ |
| molar volume of an ideal gas, 1 atm, 0 °C | $22.41397\ \text{L}\ \text{mol}^{-1}$ |
| molar volume of an ideal gas, 1 bar, 0 °C | $22.71095\ \text{L}\ \text{mol}^{-1}$ |
| neutron rest mass ($m_\text{n}$) | $1.6749275 \times 10^{-27}$ kg |
| Planck’s constant ($h$) | $6.62607015 \times 10^{-34}$ J s |
| proton rest mass ($m_\text{p}$) | $1.6726219 \times 10^{-27}$ kg |
| Rydberg constant ($R$) | $1.0973731568 \times 10^{7}\ \text{m}^{-1}$ = $2.1798724 \times 10^{-18}$ J |
| speed of light (in vacuum) ($c$) | $2.99792458 \times 10^{8}\ \text{m}\ \text{s}^{-1}$ |

*Source note:* the values in this table are those of the 2022 CODATA adjustment of the fundamental physical constants, as the National Institute of Standards and Technology lists them, each given to the number of significant figures the source prints in the same place. The source’s own table mixes values from more than one adjustment, so its values do not all agree with one another. Avogadro’s number, Boltzmann’s constant, the fundamental unit of charge, Planck’s constant, and the speed of light are exact: they are the values that define the SI units. Faraday’s constant, the gas constant, and the two molar volumes follow from those exact values and are rounded here; the other values are measured.
