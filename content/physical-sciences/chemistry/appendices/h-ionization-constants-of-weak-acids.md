**Ionization Constants of Weak Acids**

|---|---|---|
| acetic | CH₃CO₂**H** | $1.8 \times 10^{-5}$ |
| arsenic | **H₃**AsO₄ | $5.5 \times 10^{-3}$ |
| arsenic | **H₂**AsO₄⁻ | $1.7 \times 10^{-7}$ |
| arsenic | **H**AsO₄²⁻ | $3.0 \times 10^{-12}$ |
| arsenous | **H₃**AsO₃ | $5.1 \times 10^{-10}$ |
| boric | **H₃**BO₃ | $5.4 \times 10^{-10}$ |
| carbonic | **H₂**CO₃ | $4.3 \times 10^{-7}$ |
| carbonic | **H**CO₃⁻ | $4.7 \times 10^{-11}$ |
| formic | HCO₂**H** | $1.8 \times 10^{-4}$ |
| hydrazoic | **H**N₃ | $2.5 \times 10^{-5}$ |
| hydrocyanic | **H**CN | $4.9 \times 10^{-10}$ |
| hydrofluoric | **H**F | $6.4 \times 10^{-4}$ |
| hydrogen peroxide | **H₂**O₂ | $2.4 \times 10^{-12}$ |
| hydrogen selenide | **H₂**Se | $1.29 \times 10^{-4}$ |
| hydrogen selenide | **H**Se⁻ | $1 \times 10^{-12}$ |
| hydrogen sulfate ion | **H**SO₄⁻ | $1.2 \times 10^{-2}$ |
| hydrogen sulfide | **H₂**S | $8.9 \times 10^{-8}$ |
| hydrogen sulfide | **H**S⁻ | $1.0 \times 10^{-19}$ |
| hydrogen telluride | **H₂**Te | $2.3 \times 10^{-3}$ |
| hydrogen telluride | **H**Te⁻ | $1.6 \times 10^{-11}$ |
| hypobromous | **H**BrO | $2.8 \times 10^{-9}$ |
| hypochlorous | **H**ClO | $2.9 \times 10^{-8}$ |
| isocyanic | **H**CNO | $2 \times 10^{-4}$ |
| nitrous | **H**NO₂ | $4.6 \times 10^{-4}$ |
| oxalic | **H₂**C₂O₄ | $6.0 \times 10^{-2}$ |
| oxalic | **H**C₂O₄⁻ | $6.1 \times 10^{-5}$ |
| phosphoric | **H₃**PO₄ | $7.5 \times 10^{-3}$ |
| phosphoric | **H₂**PO₄⁻ | $6.2 \times 10^{-8}$ |
| phosphoric | **H**PO₄²⁻ | $4.2 \times 10^{-13}$ |
| phosphorous | **H₃**PO₃ | $5 \times 10^{-2}$ |
| phosphorous | **H₂**PO₃⁻ | $2.0 \times 10^{-7}$ |
| sulfurous | **H₂**SO₃ | $1.6 \times 10^{-2}$ |
| sulfurous | **H**SO₃⁻ | $6.4 \times 10^{-8}$ |

*Source note:* the source sets all three hydrogen atoms of phosphorous acid, H₃PO₃, in bold and draws all three on oxygen atoms. Only two of them ionize, which is why the table lists two constants: in the molecule’s predominant form, HPO(OH)₂, the third hydrogen atom is bonded directly to phosphorus.

## Lewis structures

The source prints these structures in a fourth column of the table, beside each acid’s first row. Hydrogen atoms that ionize are printed in red.

*Source note:* five of the drawings are not complete Lewis structures. Nitrous acid is drawn with a single line between nitrogen and the oxygen atom that carries no hydrogen, where the molecule has a double bond; sulfurous acid is drawn with a single bond to that oxygen atom and two lone pairs on it, which leaves the atom short of an octet; and boric acid, carbonic acid, and the hydrogen sulfate ion are drawn without some or all of the lone pairs on their oxygen atoms. Formic acid’s drawing prints in red the hydrogen atom bonded to carbon as well, which does not ionize.
