We began our work solving equations in previous chapters. It has been a
while since we have seen an equation, so we will review some of the key
concepts before we go any further.

We said that solving an equation is like discovering the answer to a
puzzle. The purpose in solving an equation is to find the value or values
of the variable that make each side of the equation the same. Any value of
the variable that makes the equation true is called a **solution** to the
equation. It is the answer to the puzzle.

{{< callout type="info" >}}
  **Solution of an equation.** A solution of an equation is a value of a
  variable that makes a true statement when substituted into the equation.
{{< /callout >}}

In earlier sections, we listed the steps to determine if a value is a
solution. We restate them here.

{{< callout type="info" >}}
  **Determine whether a number is a solution to an equation.**

  1. Substitute the number for the variable in the equation.
  2. Simplify the expressions on both sides of the equation.
  3. Determine whether the resulting equation is true.
     - If it is true, the number is a solution.
     - If it is not true, the number is not a solution.
{{< /callout >}}

**Example.** Determine whether $y = \tfrac{3}{4}$ is a solution for
$4y + 3 = 8y$.

Substitute $\tfrac{3}{4}$ for $y$:

$$4\left(\tfrac{3}{4}\right) + 3 \stackrel{?}{=} 8\left(\tfrac{3}{4}\right)$$

Multiply:

$$3 + 3 \stackrel{?}{=} 6$$

Add:

$$6 = 6 \checkmark$$

Since $y = \tfrac{3}{4}$ results in a true equation, $\tfrac{3}{4}$ is a
solution to the equation $4y + 3 = 8y$.

## Solve equations using the Subtraction and Addition Properties of Equality

We introduced the Subtraction Property of Equality earlier by modeling
equations with envelopes and counters, such as $x + 3 = 8$. The
goal is to isolate the variable on one side of the equation — so we "took
away" $3$ from both sides and found the solution $x = 5$.

Some people picture a balance scale when they solve equations: one mass on
each side is balanced; two masses on each side is balanced; but one mass on
one side and two masses on the other is unbalanced.

The quantities on both sides of the equal sign in an equation are equal, or
balanced. Just as with the balance scale, whatever you do to one side of
the equation you must also do to the other to keep it balanced.

{{< callout type="info" >}}
  **Subtraction and Addition Properties of Equality.**

  Subtraction Property of Equality: for all real numbers $a$, $b$, and $c$,
  if $a = b$, then $a - c = b - c$.

  Addition Property of Equality: for all real numbers $a$, $b$, and $c$, if
  $a = b$, then $a + c = b + c$.
{{< /callout >}}

When you add or subtract the same quantity from both sides of an equation,
you still have equality. Let's review how to use the Subtraction and
Addition Properties of Equality to solve equations. We need to isolate the
variable on one side of the equation, and we check our solutions by
substituting the value into the equation to make sure we have a true
statement.

**Example.** Solve: $x - 11 = -3$.

To isolate $x$, we undo the subtraction of $11$ by using the Addition
Property of Equality, adding $11$ to each side:

$$x - 11 + 11 = -3 + 11$$

Simplify:

$$x = 8$$

Check: substitute $x = 8$ into $x - 11 = -3$:

$$8 - 11 \stackrel{?}{=} -3 \qquad -3 = -3 \checkmark$$

Since $x = 8$ makes $x - 11 = -3$ a true statement, $8$ is a solution to
the equation.

In that example, $11$ was subtracted from $x$, so we added $11$ to "undo"
the subtraction. In the next example, we need to "undo" addition by using
the Subtraction Property of Equality.

**Example.** Solve: $m + 4 = -5$.

Subtract $4$ from each side to "undo" the addition:

$$m + 4 - 4 = -5 - 4$$

Simplify:

$$m = -9$$

Check: substitute $m = -9$ into $m + 4 = -5$:

$$-9 + 4 \stackrel{?}{=} -5 \qquad -5 = -5 \checkmark$$

The solution to $m + 4 = -5$ is $m = -9$.

Now let's review solving equations with fractions.

**Example.** Solve: $n - \tfrac{3}{8} = \tfrac{1}{2}$.

Use the Addition Property of Equality, then find the LCD to add the
fractions on the right:

$$n - \tfrac{3}{8} + \tfrac{3}{8} = \tfrac{1}{2} + \tfrac{3}{8} = \tfrac{4}{8} + \tfrac{3}{8}$$

Simplify:

$$n = \tfrac{7}{8}$$

Check: substitute $n = \tfrac{7}{8}$ into the original equation:

$$\tfrac{7}{8} - \tfrac{3}{8} \stackrel{?}{=} \tfrac{1}{2} \qquad \tfrac{4}{8} \stackrel{?}{=} \tfrac{1}{2} \qquad \tfrac{1}{2} = \tfrac{1}{2} \checkmark$$

The solution checks.

$$8 - 3.7 \stackrel{?}{=} 4.3 \qquad 4.3 = 4.3 \checkmark$$

## Solve equations that need to be simplified

In the examples up to this point, we have been able to isolate the
variable with just one operation. Many of the equations we encounter in
algebra will take more steps to solve. Usually, we will need to simplify
one or both sides of an equation before using the Subtraction or Addition
Properties of Equality. You should always simplify as much as possible
before trying to isolate the variable.

**Example.** Solve: $3x - 7 - 2x - 4 = 1$.

The left side of the equation has an expression that we should simplify
before trying to isolate the variable. Rearrange the terms using the
Commutative Property of Addition, then combine like terms:

$$
\begin{array}{rcl}
3x - 7 - 2x - 4 &=& 1 \\[4pt]
3x - 2x - 7 - 4 &=& 1 \\[4pt]
x - 11 &=& 1
\end{array}
$$

Add $11$ to both sides to isolate $x$, then simplify:

$$
\begin{array}{rcl}
x - 11 + 11 &=& 1 + 11 \\[4pt]
x &=& 12
\end{array}
$$

Check by substituting $x = 12$ into the original equation:

$$3(12) - 7 - 2(12) - 4 \stackrel{?}{=} 1$$

$$
\begin{array}{rcl}
36 - 7 - 24 - 4 &\stackrel{?}{=}& 1 \\[4pt]
29 - 24 - 4 &\stackrel{?}{=}& 1 \\[4pt]
5 - 4 &\stackrel{?}{=}& 1 \\[4pt]
1 &=& 1 \checkmark
\end{array}
$$

The solution checks.

Some equations have parentheses that must be distributed before we can
combine like terms.

**Example.** Solve: $3(n - 4) - 2n = -3$.

The left side has an expression we should simplify. Distribute on the
left, use the Commutative Property to rearrange terms, then combine like
terms:

$$
\begin{array}{rcl}
3(n - 4) - 2n &=& -3 \\[4pt]
3n - 12 - 2n &=& -3 \\[4pt]
3n - 2n - 12 &=& -3 \\[4pt]
n - 12 &=& -3
\end{array}
$$

Isolate $n$ using the Addition Property of Equality, then simplify:

$$
\begin{array}{rcl}
n - 12 + 12 &=& -3 + 12 \\[4pt]
n &=& 9
\end{array}
$$

Check by substituting $n = 9$ into the original equation:

$$
\begin{array}{rcl}
3(9 - 4) - 2 \cdot 9 &\stackrel{?}{=}& -3 \\[4pt]
3(5) - 18 &\stackrel{?}{=}& -3 \\[4pt]
15 - 18 &\stackrel{?}{=}& -3 \\[4pt]
-3 &=& -3 \checkmark
\end{array}
$$

The solution checks.

{{< fillin
  question="Solve: $5(p - 3) - 4p = -10$."
  answer="5"
  answerForm="decimal"
  hint="Distribute the $5$ on the left, combine like terms, then isolate $p$."
>}}

Sometimes both sides of the equation need to be simplified before we
isolate the variable.

**Example.** Solve: $2(3k - 1) - 5k = -2 - 7$.

Both sides have expressions we should simplify first. Distribute on the
left and combine the constants on the right, then use the Commutative
Property to rearrange terms and combine like terms:

$$
\begin{array}{rcl}
2(3k - 1) - 5k &=& -2 - 7 \\[4pt]
6k - 2 - 5k &=& -9 \\[4pt]
6k - 5k - 2 &=& -9 \\[4pt]
k - 2 &=& -9
\end{array}
$$

Undo the subtraction by using the Addition Property of Equality, then
simplify:

$$
\begin{array}{rcl}
k - 2 + 2 &=& -9 + 2 \\[4pt]
k &=& -7
\end{array}
$$

Check by substituting $k = -7$ into the original equation:

$$2(3(-7) - 1) - 5(-7) \stackrel{?}{=} -2 - 7$$

$$
\begin{array}{rcl}
2(-21 - 1) - 5(-7) &\stackrel{?}{=}& -9 \\[4pt]
2(-22) + 35 &\stackrel{?}{=}& -9 \\[4pt]
-44 + 35 &\stackrel{?}{=}& -9 \\[4pt]
-9 &=& -9 \checkmark
\end{array}
$$

The solution checks.

## Translate an equation and solve

In previous chapters, we translated word sentences into equations. The
first step is to look for the word (or words) that translate(s) to the
equal sign — words like *is*, *is equal to*, *is the same as*, *the result
is*, *gives*, *was*, and *will be* all translate to $=$.

{{< callout type="info" >}}
  **Translate a word sentence to an algebraic equation.**

  1. Locate the "equals" word(s). Translate to an equal sign.
  2. Translate the words to the left of the "equals" word(s) into an
     algebraic expression.
  3. Translate the words to the right of the "equals" word(s) into an
     algebraic expression.
{{< /callout >}}

**Example.** Translate and solve: five more than $x$ is equal to $26$.

Translate "five more than $x$" as $x + 5$ and "is equal to" as $=$:

$$x + 5 = 26$$

Subtract $5$ from both sides, then simplify:

$$x + 5 - 5 = 26 - 5 \qquad\qquad x = 21$$

Check: is $26$ five more than $21$?

$$21 + 5 \stackrel{?}{=} 26 \qquad 26 = 26 \checkmark$$

The solution checks.

**Example.** Translate and solve: the difference of $5p$ and $4p$ is $23$.

Translate "the difference of $5p$ and $4p$" as $5p - 4p$ and "is" as $=$:

$$5p - 4p = 23$$

Simplify the left side:

$$p = 23$$

Check by substituting $p = 23$ into the original equation:

$$
\begin{array}{rcl}
5(23) - 4(23) &\stackrel{?}{=}& 23 \\[4pt]
115 - 92 &\stackrel{?}{=}& 23 \\[4pt]
23 &=& 23 \checkmark
\end{array}
$$

The solution checks.

## Translate and solve applications

In most of the application problems we solved earlier, we were able to
find the quantity we were looking for by simplifying an algebraic
expression. Now we will use equations to solve application problems. We'll
start by restating the problem in just one sentence, assign a variable,
and then translate the sentence into an equation to solve. When assigning
a variable, choose a letter that reminds you of what you are looking for.

**Example.** The Robles family has two dogs, Buster and Chandler. Together,
they weigh $71$ pounds. Chandler weighs $28$ pounds. How much does Buster
weigh?

Identify what you are asked to find, and choose a variable to represent
it: how much does Buster weigh? Let $b =$ Buster's weight.

Write a sentence that gives the information to find it, then restate it
including the given information: Buster's weight plus Chandler's weight
equals $71$ pounds — Buster's weight plus $28$ equals $71$.

Translate the sentence into an equation, using the variable $b$:

$$b + 28 = 71$$

Solve the equation:

$$b + 28 - 28 = 71 - 28 \qquad\qquad b = 43$$

Check the answer in the problem: is $43$ pounds a reasonable weight for a
dog? Yes. Does Buster's weight plus Chandler's weight equal $71$ pounds?

$$43 + 28 \stackrel{?}{=} 71 \qquad 71 = 71 \checkmark$$

Write a complete sentence that answers the question: Buster weighs $43$
pounds.

{{< callout type="info" >}}
  **Devise a problem-solving strategy.**

  1. Read the problem. Make sure you understand all the words and ideas.
  2. Identify what you are looking for.
  3. Name what you are looking for. Choose a variable to represent that
     quantity.
  4. Translate into an equation. It may be helpful to restate the problem
     in one sentence with all the important information. Then, translate
     the English sentence into an algebra equation.
  5. Solve the equation using good algebra techniques.
  6. Check the answer in the problem and make sure it makes sense.
  7. Answer the question with a complete sentence.
{{< /callout >}}

**Example.** Shayla paid $\text{\textdollar}24{,}575$ for her new car. This
was $\text{\textdollar}875$ less than the sticker price. What was the
sticker price of the car?

Identify what you are asked to find: "What was the sticker price of the
car?" Assign a variable: let $s =$ the sticker price of the car.

Write a sentence that gives the information to find it: $\text{\textdollar}24{,}575$
is $\text{\textdollar}875$ less than the sticker price — $24{,}575$ is
$875$ less than $s$.

Translate into an equation:

$$24{,}575 = s - 875$$

Solve:

$$
\begin{array}{rcl}
24{,}575 + 875 &=& s - 875 + 875 \\[4pt]
25{,}450 &=& s
\end{array}
$$

Check: is $875$ less than $25{,}450$ equal to $24{,}575$?

$$
\begin{array}{rcl}
25{,}450 - 875 &\stackrel{?}{=}& 24{,}575 \\[4pt]
24{,}575 &=& 24{,}575 \checkmark
\end{array}
$$

The sticker price was $\text{\textdollar}25{,}450$.

## Key terms

**solution of an equation** — a value of a variable that makes a true
statement when substituted into the equation. **Subtraction Property of
Equality** — for all real numbers $a$, $b$, and $c$, if $a = b$, then
$a - c = b - c$. **Addition Property of Equality** — for all real numbers
$a$, $b$, and $c$, if $a = b$, then $a + c = b + c$.
