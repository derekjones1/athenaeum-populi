{{- /* Athenaeum Populi — hold the punctuation after inline math on the formula's line. `_markup/render-passthrough.html` marks each inline formula of the body with `…` (it says why, and why not CSS alone). Here the formula and the punctuation typed straight after it — `. , ; : ? ! )` and a closing quote, any run of them — become one `.ap-math-glue` span, and every marker is removed. A label typed before the formula, "(ii) ", and a value typed after it, " = 180.5 kJ", join the same span (`_partials/math-glue-patterns.html` says which and why). The pattern must never run from one formula's start to a LATER formula's end. RE2 has no lookahead, so the body is written as "no comment inside": any character but `<`, or a `<` not followed by `!`. KaTeX's output holds no comment, and neither does the `.ap-math-keep` span around it. Call: {{ partial "glue-math.html" .Content }} Returns trusted HTML. */ -}} {{- $html := printf "%s" . -}} {{- if in $html "" -}} {{- $re := partialCached "math-glue-patterns.html" "math-glue" -}} {{- $math := `((?:[^<]|<[^!])*)` -}} {{- $punct := `(?:[.,;:?!)’”]|’|”)` -}} {{- /* A label before the formula, with any value and punctuation after it. */ -}} {{- $html = replaceRE (printf `(^|[\s>])(%s) %s((?:%s)?%s*)` $re.label $math $re.value $punct) `${1}${2} ${3}${4}` $html -}} {{- /* A value after the formula, with any punctuation after that. */ -}} {{- $html = replaceRE (printf `%s(%s%s*)` $math $re.value $punct) `${1}${2}` $html -}} {{- /* Punctuation alone. */ -}} {{- $html = replaceRE `((?:[^<]|<[^!])*)((?:[.,;:?!)’”]|’|”)+)` `$1$2` $html -}} {{- $html = replace (replace $html "" "") "" "" -}} {{- end -}} {{- return ($html | safeHTML) -}}
