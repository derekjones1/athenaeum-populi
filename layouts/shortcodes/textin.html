{{- /* textin — short TEXT answer (a term, a name, a short phrase) graded in the browser by normalized exact match. The word counterpart of `fillin`, whose math input cannot take words at all; the lint routes word answers here and value answers there. Params: question (required) prose prompt — no `$…$` math (a text field has no speech serializer; use multiplechoice when the prompt needs math) answer (required) the keyed answer, plain text accept optional `|`-separated alternates (irregular plural, British spelling, abbreviation) graded as correct too; a regular s/es plural, and the regular singular of a plural, is folded by the grader and must not be listed answerForm optional: "formula" or "equation" — the answer is a chemical formula (`Mn₃(PO₄)₂`, `SO₄²⁻`) or a balanced equation, read by check-chem.mjs with its capitals, subscripts, charges, and coefficients, where a word is read without them hint optional hint Nothing else: `answerDisplay` and `placeholder` were accepted for a year and set by no page (the keyed word IS the display; the field's prompt is always "Your answer"), so they are refused rather than silently ignored. Grading lives in assets/js/lib/text/check-text.mjs; the component (assets/js/components/text/text-in.js) upgrades this static shell. */ -}} {{- $question := .Get "question" -}} {{- $answer := .Get "answer" -}} {{- if or (not (trim ($question | default "") " ")) (not (trim ($answer | default "") " ")) -}} {{- errorf "textin shortcode needs both a non-empty 'question' and 'answer' (%s)" .Position -}} {{- end -}} {{- with .Get "answerMode" -}} {{- errorf "textin does not take \"answerMode\" — it grades words, not values; use fillin for a math answer (%s)" $.Position -}} {{- end -}} {{- $answerForm := .Get "answerForm" | default "" -}} {{- if and $answerForm (not (in (slice "formula" "equation") $answerForm)) -}} {{- errorf "textin answerForm %q is not a text form — use \"formula\" or \"equation\"; a numeric answer is a fillin (%s)" $answerForm .Position -}} {{- end -}} {{- range (slice "answerDisplay" "placeholder") -}} {{- with $.Get . -}} {{- errorf "textin does not take %q — the keyed word is the display and the field prompt is fixed (%s)" . $.Position -}} {{- end -}} {{- end -}} {{- range (slice "question" "answer" "accept" "hint") -}} {{- $value := $.Get . | default "" -}} {{- if findRE `(^|[^\\])\$` (printf "%v" $value) -}} {{- errorf "textin %q must not contain `$` math — a text field has no spoken-math name; use multiplechoice for a prompt that needs math (%s)" . $.Position -}} {{- end -}} {{- end -}}
