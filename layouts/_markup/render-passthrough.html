{{- /* Athenaeum Populi — build-time KaTeX passthrough render hook. Math is rendered by Hugo's pinned transform.ToMath implementation and ships as static HTML+MathML. There is intentionally no client-side/CDN fallback: an authoring error must fail the build instead of becoming a runtime fetch. A short inline number in scientific notation is wrapped in `.ap-math-keep` (white-space: nowrap). KaTeX lets inline math break after a binary operator, so `1.497 \times 10^{-3}` could end one line at "×" and start the next at "10⁻³", and a learner reads the given value as 1.497. Only that shape is held together: a long inline expression stays free to wrap on a phone. Punctuation after inline math. A browser may break a line between an inline-block and the text after it, and KaTeX sets every piece of a formula as one, so the period, comma, or bracket after a formula could start the next line alone (29,589 formulas in the library are followed by one). This hook cannot see the text after its span, so it only marks where the span begins and ends, with two comments; `_partials/glue-math.html`, called on the page's whole content by `layouts/docs/single.html` and `list.html`, moves the formula and its punctuation into `.ap-math-glue` (white-space: nowrap) and takes the comments out — with an opening bracket or quote typed straight before the formula, which could end a line alone the same way (426 formulas in the library follow one). A comment left behind by a template that does not call the partial is inert; `check:build` refuses one all the same. Inside a no-wrap box a formula would lose the breaks KaTeX allows after its operators — between its `.base` pieces — and a long one would run off a phone. So every inline formula carries a `` between its pieces: hidden by default (custom.css), shown inside `.ap-math-glue`, where it gives back exactly the breaks the formula had. The other approach, a no-wrap wrapper with wrapping restored on the formula inside it, does not hold in Chrome: the break after an inline-block is decided by the inline-block's own parent, and survives the closing tags after it. */ -}} {{- $engine := site.Params.math.engine | default "katex" -}} {{- if eq $engine "katex" -}} {{- $opts := dict "output" "htmlAndMathml" "displayMode" (eq .Type "block") -}} {{- with try (transform.ToMath .Inner $opts) -}} {{- with .Err -}} {{- errorf "transform.ToMath failed to render math (%s): %s" $.Position . -}} {{- else -}} {{- if eq $.Type "block" -}} {{- .Value -}} {{- else -}} {{- $math := replace (printf "%s" .Value) `` `` -}} {{- if and (le (len $.Inner) 60) (findRE `\\times\s*10\^` $.Inner 1) -}} {{- $math = printf `%s` $math -}} {{- end -}} {{- printf "%s" $math | safeHTML -}} {{- end -}} {{- $.Page.Store.Set "hasMath" true -}} {{- end -}} {{- end -}} {{- else -}} {{- errorf "unsupported math engine %q (%s)" $engine .Position -}} {{- end -}}
