# Archive — closed records, not reading for a run

Everything here is finished work kept for the record. No brief, playbook,
or run recipe points an agent into this folder for instructions; read a
file here only when a question is specifically about what one of these
closed programmes did.

- `re-review.md` — the re-review campaign (September 22 – October 13,
  2026): how it was run, the tracker at close, the retired figure
  conversion brief, and the alt-only figure pass.
- `reverification-biology.md`, `reverification-microbiology.md` — the
  figure-alt passes, practice sweeps and long-description passes,
  re-review rows, whole-page leak reads, and alt-only figure passes that
  brought the two books authored before the three-reading discipline up
  to the Anatomy and Physiology standard (September 20–26, 2026), cut
  verbatim from their history files.
- `alt-pass/` — the figure-alt pass kit (checker brief and run shape) that
  ran those passes, with `tools/source/alt-pass-packets.py` still building
  its packets. **A book authored under the triple check does not run this
  pass** (Derek, November 2, 2026; `docs/subjects/life-sciences.md`
  "Completion audit"): Anatomy and Physiology's completion audit measured
  its figures by cold sample instead and the book was closed without it.
  The kit is here so the pass can be re-run if a later measurement calls
  for it.

Why a separate folder: these records were being loaded as context for
chapter runs and re-reviews that no longer need them. The dated narrative
that still informs a run stays in `docs/history/`.
