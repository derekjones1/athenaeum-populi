## What to read, on every page

1. **Every hint of every item, key covered**: does it state the key, the
   fact that decides the item, the arithmetic on the item's own numbers, or
   point at the one row or sentence that prints the whole answer?
2. **Every stem a ruling reworded** (your task lists the rulings' cases):
   does a rewritten question name what its blank held; do the options and
   the key still match the module's sentence; does every "previous
   item(s)" reference point at the right items, counted on the page as it
   stands; is an added sentence only on the items that need it?
3. **Every selfcheck rubric that was rewritten**: each clause a whole
   statement in the model answer's own words that checks something; can
   the page's own model answer meet every clause; for a "Sample answer:"
   model answer, the rubric is the criteria sentence's, not the sample's
   details.
4. **Every `*Source note:*`**: true, says what the source prints, cites its
   authority, sits after the paragraph — or the figure that paragraph
   introduces — and, beside an unanswered item, lets no key be worked out.
   Recompute any number it corrects from the page's own tables.
5. **Every footer's `Changes:` clause against the page as it stands**: each
   clause true, each departure you can see named, no key printed, counts
   right.
6. **Any place one page now does what another page does differently**
   after the general rulings.
